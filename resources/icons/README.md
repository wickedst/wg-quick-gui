# WireGuard icon

Source: [Simple Icons — WireGuard](https://github.com/simple-icons/simple-icons/blob/develop/icons/wireguard.svg), released under CC0 1.0.

The assets contain only the WireGuard dragon on a transparent background. Four colour variants are provided:

- Dark panels: white when active, dark grey (`#666666`) when inactive
- Light panels: black when active, light grey (`#999999`) when inactive

PNG and ARGB files are rendered from the SVGs. ARGB data is embedded in the Rust binary so the tray does not depend on a system icon theme.
