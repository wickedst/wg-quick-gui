# WireGuard icon

Source: [Simple Icons — WireGuard](https://github.com/simple-icons/simple-icons/blob/develop/icons/wireguard.svg), released under CC0 1.0.

The SVG has been given the WireGuard brand-red circular background and a white glyph. The PNG and ARGB files are rendered from that SVG. ARGB data is embedded in the Rust binary so the tray does not depend on a system icon theme.
